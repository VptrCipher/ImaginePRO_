# Using ImaginePro

Open **ImaginePro.exe** after completing the [initial setup](docs/SETUP.md).
The studio opens in your browser and reuses the background application when
it is already running.

## Generate a video

1. Create or select a project.
2. Import footage, a voice recording, or a transcript. You can also paste text.
3. Choose your visual style and portrait or landscape format.
4. Describe the story, pacing, captions, and animation you want.
5. Press **Enter** or click **Generate**.

The finished video appears on the timeline automatically. Review it in the
preview player, make adjustments, and export the result.

## Refine your edit

Select a clip to trim its start and end, change volume or zoom, cut it at the
playhead, or delete it. Reorder clips and use undo/redo while editing.
Render a preview after manual changes to review the final effects.

Use **Enhance Director** to improve your prompt before generation. Review the
rewritten instructions and use Undo if you prefer the previous version.

## Settings and projects

Settings shows the generation connection and available configuration fields.
The prompt enhancement connection is configured separately.

Projects retain their imported media, timeline revisions, and generated files
on the rendering computer. Keep the application folder in place when using
desktop shortcuts.

## Online demo

Open [ImaginePro](https://imaginepro-demo.vercel.app) and enter your demo
passcode. Keep the connected rendering computer on, awake, and online.
The online demo workspace is separate from the desktop workspace.

See [online operation](docs/VERCEL-DEMO.md) and
[desktop diagnostics](docs/DESKTOP.md) for connection details.
